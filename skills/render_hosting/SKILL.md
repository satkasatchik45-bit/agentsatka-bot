# Ko'nikma: render_hosting

## 🎯 Tavsif
Render.com platformasiga Python Telegram botlari va Web ilovalarni 24/7 rejimida avtomatik va bepul joylashtirish (deploy) ko'nikmasi.

## 📋 Ko'rsatma va Algoritm
1. Render API orqali akkount (owner ID) ma'lumotlarini tekshirish.
2. Bot/Ilova uchun GitHub ombori (repository) yoki Render Web Service / Background Worker yaratish.
3. Kerakli muhit o'zgaruvchilarini (BOT_TOKEN, API_KEY va b.) sozlash.
4. Automatic Deploy yoki manual deploy trigger berish.
5. Deploy jarayoni loglarini kuzatish va holatni tekshirish.
